## Privacy

Never write real personal data into any committed file: no real dates or cycle details from actual use (last-period dates, cycle length, current day or phase), no usernames, and no local folder paths. Use invented dates in examples, tests and logs, and replace local paths with a placeholder. This repository is public.

## Planning log

Whenever we decide something about this project — a requirement, a number, a name, a tool — append one line to PLANNING_LOG.md: the date, what was decided, and whether I decided it or you did. Never rewrite an earlier line.
