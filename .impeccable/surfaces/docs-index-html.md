# Surface brief: promo page (docs/index.html)

Visitor mode: Persuade. Full brief: designs/promo-page-brief.md (confirmed 2026-11-13).

Audience: course classmates, mostly alone via a shared link on laptop or phone, sometimes shown briefly in the demo. Takeaway: "it tells you when it's guessing". Action: the Try it template. Proof: the two verbatim output blocks, the 2/4/1/5 scoreboard, EVIDENCE.md. Constraints: PROMO.md wording verbatim, system font stack, no JavaScript, no third-party requests.

Open: ground colour, red vs strict black-on-white, decided by the user through generate.

## Direction contract

THESIS: The page is one food-label panel that grades its own claims. It refuses the developer-tool landing (dark hero, terminal beside headline, feature-card row) and the wellness landing (soft gradients, cycle wheel).

OWN-WORLD: White label stock framed by a heavy black border; rules in three weights (hairline, medium, heavy bar) do all the structuring; heavy condensed-feeling sans from the system stack for headings, dense label rows, tabular numerals; output in the system monospace. Evidence grades are black-ink marks: Strong inverted, Moderate solid box, Weak dashed box, Speculative dotted box. No cards, no shadows, no rounded corners.

STORY: The visitor reads the headline as the label's product name, sees day 3's real foods graded Strong/Moderate and day 14's placeholders graded Speculative/Weak in the same panel, reads the 2/4/1/5 bottom row, and leaves remembering that the tool says when it's guessing; curious ones copy the Try it template.

FIRST VIEWPORT: One label panel, centred, about 40rem wide on desktop and full width on phones. Top: the headline at the largest size, set heavy across the panel; under it a hairline and the product name row, then the opening paragraph, then the heavy bar, then the start of the day-3 section with its caption.
